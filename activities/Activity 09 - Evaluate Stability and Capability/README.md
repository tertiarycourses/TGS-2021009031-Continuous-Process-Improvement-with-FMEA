# Activity 09 — Evaluate Stability and Capability

**Course:** Continuous Process Improvement with FMEA (TGS-2021009031)  
**Assessment mapping:** A9, A10, K4  
**Objective:** Monitor improvement performance using time order, control limits and capability measures.

## Scenario

After the pilot, Orion has 30 daily solder-paste-volume samples and bridge-defect results.

## Deliverable

1. Why can a stable process still be incapable?

## Acceptance criterion
