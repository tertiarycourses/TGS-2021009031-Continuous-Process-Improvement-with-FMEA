# Activity 04 — Verify Root Causes with Fishbone, 5 Whys and Fault Tree

**Course:** Continuous Process Improvement with FMEA (TGS-2021009031)  
**Assessment mapping:** A3, A4  
**Objective:** Analyse evidence and build a defensible causal explanation for the leading defect.

## Scenario

Solder bridging is concentrated on Printer P2 during the late shift, but the causal mechanism is not yet verified.

## Deliverable

6M Fishbone, evidence-backed 5 Whys, fault tree and cause-verification matrix

## Files

- `Starter.xlsx` — your working file.
- `Completed.xlsx` — a worked comparison; review after attempting the activity.
- `Activity-Brief.pdf` — printable scenario, questions and submission check.
- `Checklist.md` — final verification.

## Scenario questions

1. Which cause is a mechanism rather than a label?
2. What observation would disconfirm the preferred explanation?

## Acceptance criterion

At least one cause is supported by a reproducible evidence test, the fault-tree logic is valid, and no conclusion relies on blame.
