# Activity 03 — Prioritise the Defect Pattern with Pareto Analysis

**Course:** Continuous Process Improvement with FMEA (TGS-2021009031)  
**Assessment mapping:** A3, A4  
**Objective:** Gather, validate and interpret production information to focus the investigation.

## Scenario

Orion has 240 inspection records across products, shifts and printing machines but anecdotes point in different directions.

## Scenario questions

1. What is the leading defect and how much of the total does it represent?
2. Which stratum shows the strongest signal, and what limitation remains?

## Acceptance criterion

The Pareto counts reconcile to the source, cumulative percentage reaches 100%, and the conclusion distinguishes priority from cause.
