# Activity 05 — Build the Orion Process FMEA

**Course:** Continuous Process Improvement with FMEA (TGS-2021009031)  
**Assessment mapping:** A5, A6, K3  
**Objective:** Apply structure, function and failure analysis to the scoped SMT process.

## Scenario

The team must turn the SIPOC, process flow, defect evidence and RCA findings into a traceable PFMEA.

## Deliverable

PFMEA header, process/function structure and at least eight complete failure chains

## Files

- `Completed.xlsx` — a worked comparison; review after attempting the activity.
- `Activity-Brief.pdf` — printable scenario, questions and submission check.
- `Checklist.md` — final verification.

1. Does each failure mode describe loss of a stated function?

## Acceptance criterion
