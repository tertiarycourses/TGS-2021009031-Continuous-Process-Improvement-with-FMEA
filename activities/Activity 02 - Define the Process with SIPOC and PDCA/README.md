# Activity 02 — Define the Process with SIPOC and PDCA

**Course:** Continuous Process Improvement with FMEA (TGS-2021009031)  
**Assessment mapping:** A1, A2, K1  
**Objective:** Set a process boundary and convert the improvement goal into a testable PDCA plan.

## Scenario

The team disagrees about whether stencil preparation, printing, placement or reflow belongs in scope.

## Deliverable

SIPOC, five-stage SMT process map, stakeholder needs and PDCA experiment canvas

## Files

- `Starter.xlsx` — your working file.
- `Completed.xlsx` — a worked comparison; review after attempting the activity.
- `Activity-Brief.pdf` — printable scenario, questions and submission check.
- `Checklist.md` — final verification.

## Detailed procedure

## Scenario questions

1. What is deliberately out of scope?
2. Which requirement will later appear as a function in the PFMEA?

## Acceptance criterion

The SIPOC boundary is unambiguous and the PDCA hypothesis contains change, predicted outcome, measure and guardrail.
