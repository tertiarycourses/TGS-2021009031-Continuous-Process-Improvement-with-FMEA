## About the course

Learners build a continuous improvement system for one connected case, Orion Precision Electronics: they define the process, prioritise and verify root causes, construct and re-score a Process FMEA, select and pilot improvements, evaluate stability and capability, and close the loop with a Process Control Plan.

## Learning outcomes

- ELO1: Create a continuous process improvement system.
- ELO2: Perform root cause analysis for continuous process improvement.
- ELO3: Design and apply Failure Mode and Effects Analysis (FMEA).
- ELO4: Identify and direct improvement opportunities.
- ELO5: Manage and evaluate improvement with a Process Control Plan.

## Topics covered

1. Introduction to Continuous Process Improvement
2. Root Cause Analysis
3. Design and Apply FMEA
4. Identify and Direct Improvement Opportunities
5. Manage Improvement with a Process Control Plan
